# HotShop
E-Commerce Project for Sporting Equipments with the features of Admin, Seller and Customer

Developed an E-commerce Website using React and Redux at Front-end. JWT Authentication, Springboot, Java Mail Sender, JPA for simplified CRUD operations at Back-end with MySQL as Database both connected using Hibernate at the Backend. Razorpay is used as payment gateway. Frontend is connected to the backend using Axios and Used Gemini API as AI chatbot for customer support services. Website consists of Admin, Seller, Customer panels which provides a vast user experience.
